# 国际版在线安装：Windows 8.x 两层检查修补

**2026-11-10：Test4 已在 Windows 8.1 成功完成安装。** 本次原始在线引导器资源版本 12.1.0.25872，实际下载的 AMD64 安装包为 12.1.0.29681。

## 使用

1. 将自己下载的原始在线引导器放入 `Patch/Original`，保留文件名 `wps_wid.cid-424762483.1792948203(1).exe`；也可把原始 EXE 拖到启动 CMD。
2. 关闭之前的安装界面，以管理员身份运行 `Patch/Start_Online_Test4.cmd`。
3. 保持控制台打开，按官方界面继续下载及安装，之前下载的原始缓存包无需清除。

需要 64 位 Windows PowerShell 4.0 或更新版本。全部所需源码均在本目录 Patch 内，不依赖其它版本方案。仓库不提供原始或修补后的厂商安装器。

脚本在进程启动时验证并修改内存中的两层系统支持检查，磁盘 EXE 与原签名不变；C# 有界读取和编译后的检测器解决了 Test2/3 分析期间长时间停在 0% 的问题。
