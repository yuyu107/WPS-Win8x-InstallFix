# 普通版参考构建的定位与修补

本目录研究的 12.1.0.29158 为 NSIS 32 位外壳与 AMD64 内层 EXE。原安装器提示仅允许 Windows 7、10、11，用户报告 Windows 7 兼容模式仍被拦截；修补内层共享系统检查后已进入安装界面。

## 参考构建位置

| 项目 | 值 |
| --- | --- |
| 函数首选 VA | `0x1400C3280` |
| 文件偏移 | `0xC2680` |
| 原六字节 | `40 53 48 83 EC 20` |
| 新六字节 | `B8 01 00 00 00 C3` |

修改使本项系统支持函数返回完整 EAX=1，不修改 Windows 的全局版本报告。上述位置只描述参考样本；新构建通过函数模板和结构守卫动态定位。

界面成功打开与完整安装、组件运行是不同验证范围。当前没有足够证据确认厂商的决策动机，也未记录导致普通兼容模式失效的完整动态 API 调用链。
