# WPS Office Windows 8.x 安装拦截技术分析

## 一、到底发生了什么？

对于本项目研究的 WPS Office 中国大陆版 **12.1.0.29158 x64** 和国际版离线包 **12.1.0.29162 x64**，原版安装器会在 Windows 8.x 上阻止进入安装界面。弹窗声明仅支持 Windows 7、Windows 10、Windows 11。用户试过 Windows 7 兼容模式仍无法绕过；针对内层版本检查函数修补之后，两个构建均已在测试环境**进入安装界面**。

这与以下三件事不同：
1. **厂商声明支持**：只列出某些操作系统，并不一定说明其他系统完全无法运行。
2. **安装器允许进入**：只是通过安装程序的版本检查，不代表完成安装或 WPS 各组件工作正常。
3. **实际运行兼容**：需要新建、编辑、保存、更新和卸载等单独验证。

为什么 WPS 厂商采用这一支持名单，目前没有足够资料确认；「为了减少支持成本」等理由只能作为假设，不能当作官方结论。国际版网页的兼容性说明也不能覆盖所有离线/在线构建。

## 二、两种离线安装包

| 构建 | 类型 | 结构 | 用户测试 |
| --- | --- | --- | --- |
| 12.1.0.29158 | 中国大陆版 x64 离线包 | NSIS 32 位外壳 + x64 内层 EXE | 修补后进入安装界面 |
| 12.1.0.29162 | 国际版 x64 离线包 | NSIS 32 位外壳 + x64 内层 EXE | 修补后进入安装界面 |

两者内层的共享版本检查函数入口相同，**不应由此推断所有版本都具有相同地址**。当前只允许对照 [Supported-Builds.md](Supported-Builds.md) 中的完整文件 SHA-256 修补。

## 三、定位与修补

已识别的内层 x64 版本检查函数：

- 虚拟地址：`0x1400C3280`
- 文件偏移：`0xC2680`
- 原入口 6 字节：`40 53 48 83 EC 20`
- 新入口 6 字节：`B8 01 00 00 00 C3`

```asm
mov eax, 1
ret
```

含义为：该函数被调用时立即返回 1，而不是继续判断操作系统。这项改动**不修改 Windows 本身，也不让其他程序误认为当前系统是 Windows 7**。

早期 v0.1 修补外围两个调用点，没有解除 GUI 安装拦截；v0.2 修补共享函数后，29158 的安装界面能够打开；对 29162 采用同一原理后也得到相同反馈。早期尝试是定位过程中的实验，不是不同操作系统完整兼容性的证明。

## 四、为什么 Windows 7 兼容模式无效？

普通兼容模式是 Windows 的应用兼容性机制，并非一套完整虚拟的 Windows 7。版本信息可能来自多个 API、模块资源、进程与内部判断。即便某个版本接口受到兼容层影响，也不表示所有检查都会读到相同版本。

安装器静态代码中能够看到版本检查相关接口，例如 `VerifyVersionInfoW`，以及读取文件版本信息的路径；然而这些引用**不能证明**某个具体 API 一定在本次失败运行中执行。版本判断也可能发生于兼容层没有覆盖的子进程中。

**目前已被实测证明的是结果差异：** Windows 7 兼容模式仍被拦截，但共享函数返回值修补能够通过安装界面之前的检查。要确定究竟是哪一条路径导致兼容模式无效，应在原版安装器上使用调试器，记录实际调用链、进程关系与返回值，而不是仅凭静态字符串做结论。

微软参考：
- [GetVersionExW](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-getversionexw)
- [VerifyVersionInfoW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-verifyversioninfow)
- [GetFileVersionInfoW](https://learn.microsoft.com/en-us/windows/win32/api/winver/nf-winver-getfileversioninfow)

## 五、风险、适用范围及后续研究

- 当前支持且验证过静态补丁的仅为两个特定 x64 离线构建。
- 文件原始 SHA-256、解压后的内层 SHA-256、修改前字节、修改后 SHA-256 均严格校验。
- 生成的修补 EXE 原厂签名失效，适合先在可回滚虚拟机验证。
- 目前只确认进入安装界面，并未全面验证安装进度、文字/表格/演示、更新器及卸载。
- 后续可研究 x86 构建、具体运行时检测路径，以及不依赖固定文件偏移的安全特征识别。
